# darkness-fall
A 2d top-down zombie shooter project built with **Godot Engine**.

> *Survive a wave of zombies, manage health and ammos to last longer*

---

## 🎮 Features & Mechanics
* **Top-Down Player Movement:** Smooth movement using Godot's `CharacterBody2D`.
* **Enemy AI:** zombie chases you down, know your location
* **Health and Damage system:** Health slowly drains while zombie is touching you, you can use weapons to retaliate
* **Basic Custom Assets:** All arts and sprites created from scratch.

---

## 🛠️ Built With
* **Engine:** [Godot Engine 4.7.2](https://godotengine.org/)
* **Language:** GDScript
* **Art and Tools:** Custom 2D Sprites

---
